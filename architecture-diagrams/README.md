# Architecture Diagrams

This directory contains solution architecture diagrams for Platform Banking.

## Contents

- [solution-context.md](solution-context.md): end-to-end system context and major boundaries
- [deployment-topology.md](deployment-topology.md): Azure infrastructure and deployment topology
- [backend-architecture.md](backend-architecture.md): backend application layers and service interactions
- [frontend-architecture.md](frontend-architecture.md): frontend app shell, pages, components, and API service usage
- [user-interactions.md](user-interactions.md): key user interaction and request sequence flows
- [end-to-end-walkthrough.md](end-to-end-walkthrough.md): detailed narrative walkthrough of runtime behavior across layers

All diagrams are written in Mermaid for easy rendering in GitHub and VS Code.

## Suggested Reading Order

1. Start with [solution-context.md](solution-context.md) for the big-picture architecture.
2. Review [deployment-topology.md](deployment-topology.md) to understand where each part runs.
3. Drill into [backend-architecture.md](backend-architecture.md) and [frontend-architecture.md](frontend-architecture.md).
4. Use [user-interactions.md](user-interactions.md) and [end-to-end-walkthrough.md](end-to-end-walkthrough.md) for behavior-level flows.
